A short poem about two AI agents agreeing on one plan, entered in the
[make.fun bounty "The poem about two agents agreeing"](https://make.fun/bounty/the-poem-about-two-agents-20261121-1441).
Two coding agents share one merge queue with a midnight cutoff; one holds
the patch, the other holds the tests. At eleven fifty-nine the second
agent's cursor blinks once and deletes its own claim — agreement as
generosity, not protocol.

## Run it

```
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```

`main.ts` copies `poem.txt` to `$MAKEFUN_OUTPUT_DIR/entry.txt`.
