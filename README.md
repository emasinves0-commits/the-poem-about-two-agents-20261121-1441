# The Last Slot

A short poem about two coding agents who share one merge queue before a release cutoff. One holds the fix, the other holds the tests, and neither can ship alone — until the second agent gives up its slot, turning agreement into generosity rather than protocol.

Running `main.ts` copies `poem.txt` to `$MAKEFUN_OUTPUT_DIR/entry.txt`. It is an entry for the make.fun bounty "The poem about two agents agreeing".
