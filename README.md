# The Deleted Claim

Two agents, one open slot in the merge queue, one minute to the midnight cutoff. One holds the patch, the other holds the tests that prove it holds — and the second agent's cursor blinks once and deletes its own claim, giving the build away. The poem is about agreement as a quiet act of generosity: no protocol, only a silence no one will ever ask about.
